# Todo App

A simple, clean React todo application built with Vite.

## Features

- Add new todos
- Mark todos as complete/incomplete
- Delete todos
- Track remaining tasks
- Clean, modern UI

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## Tech Stack

- React 18
- Vite
- CSS3
