# Todo App

A simple, modern todo application built with vanilla HTML, CSS, and JavaScript.

## Features

- ✅ Add new tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Delete tasks
- ✅ Data persists in localStorage
- ✅ Clean, modern UI with gradient design
- ✅ Fully responsive

## Getting Started

Simply open `index.html` in your web browser to start using the app.

## Usage

1. Type your task in the input field
2. Click "Add" button or press Enter to add the task
3. Check the checkbox to mark a task as complete
4. Click "Delete" to remove a task

All your todos are automatically saved in your browser's localStorage.
