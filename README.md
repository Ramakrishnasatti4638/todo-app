# Todo App

A simple, elegant todo list application built with vanilla HTML, CSS, and JavaScript.

## Features

- ✅ Add new tasks
- ✅ Mark tasks as complete
- ✅ Delete tasks
- ✅ Persistent storage using localStorage
- ✅ Responsive design
- ✅ Clean, modern UI

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add" or press Enter to add the task
4. Check the checkbox to mark a task as complete
5. Click "Delete" to remove a task

Your tasks are automatically saved to your browser's localStorage and will persist between sessions.
